Координаты оптимального удара

Программа ищет точку запуска `(x, y)` на сетке `0..99`, при которой в радиусе поражения оказывается максимум целей из файла.

## Запуск
nuke.exe coords.txt 10

Аргументы: путь к файлу с координатами и радиус поражения. Формат файла: на каждой строке пара целых чисел через запятую.

## Сборка

### MSVC
cl Source.c /Fe:nuke.exe


### GCC / MinGW
gcc Source.c -o nuke.exe


### Clang
clang Source.c -o nuke.exe
